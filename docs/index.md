# PydanDict documentation

PydanDict provides Pydantic models with validated mapping semantics: one
schema-defined object can be used through attribute access or mapping-oriented
code while supported changes remain atomic and validated.

The current published release is **0.3.0**. See the [release record](release.md#030-release-record)
for the immutable tag, workflow evidence and PyPI package.
